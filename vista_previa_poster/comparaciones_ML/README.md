# Comparaciones ML: vistas para Word

Las cinco imágenes de esta carpeta corresponden al perfil de 16 cm de ancho, con leyendas físicas de 9 pt. Insértelas a ese ancho para conservar el tamaño de letra.

El paquete [figuras_poster.zip](../../figuras_poster.zip) contiene el notebook ejecutado, README, fuentes, tablas y las figuras en PNG a 600 dpi, PDF y SVG. Incluye también las versiones principales de 34 cm de ancho.

Los títulos de las cajas utilizan «Nominal: … mM» y la leyenda «Concentración nominal excluida». Los valores, predicciones y selección de modelos se mantienen sin cambios.
